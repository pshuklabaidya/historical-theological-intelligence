# Explanation capability

Only the kernel may validate and publish the final response and receipt. Native constructors and typed state remain subject to the bound composition.

`Who is this argument responding to?`, `What controversy is behind this?`, `Is this aimed at a particular theologian?`, and `What pressures make this distinction important here?` select the requested [historical explanation](../../references/historical-explanation.md). Preserve explicit target, probable target, possible interlocutor, background, later analogy and unresolved identity. Oppositional resemblance does not prove a target. Build source-bound hypotheses or bounded relevant pressure records on the current argument, validate them and their existing Historical Relation Graph bindings, and use the same current publication and completion operation. Ordinary translation adds none of this analysis automatically.
