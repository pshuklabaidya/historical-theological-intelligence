# Citation

Citation-ready output must distinguish the work, edition, exemplar, and supplied image.

Use the highest securely established identity only. A minimal form is:

`Author, Short Title, established edition data if any, page/folio/signature if visible or verified, supplied image identifier, accessed YYYY-MM-DD.`

If the work is established but edition unresolved, omit the imprint and say `edition unresolved`. If the edition is established but the user's exemplar is not, cite the edition and describe the supplied copy as `unidentified exemplar`. Never import a digitized copy's shelfmark or provenance into the user's photograph.

For online witnesses, include holding institution, stable record or DOI, digitized exemplar shelfmark when given, image or canvas locator, and access date.
