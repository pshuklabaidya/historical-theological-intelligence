# Source representations

Every new task has `source-integrity.json`. Fill it before either completion route. Keep its work_id equal to the checkpoint and retain the task_directory created with task state. For a bare question without supplied or inspected source content, the empty representation lists are sufficient; source-bearing tasks record their sources. The existing `hti-source-registry.json` remains the representation interface used by Argument Dossier and historical modules; its IDs also occur in the integrity record with compatible types and direct parents. It is not a substitute for integrity state.

Read the complete production vocabulary with `python3 scripts/source_integrity.py interface`. Use literal UTF-8 text. Load `resources/templates/source-integrity.json` for the envelope. No user action is required to maintain these internal files.

## Representation ancestry

Keep SUPPLIED_PAGE_IMAGE, FACSIMILE_SCAN, RAW_OCR, CORRECTED_OCR, DIPLOMATIC_TRANSCRIPTION, NORMALIZED_TRANSCRIPTION, WITNESS_RECONSTRUCTION, HISTORICAL_TRANSLATION, MODERN_TRANSLATION, SCHOLARLY_EDITION, SECONDARY_QUOTATION, EXTRACTED_PROPOSITION and DERIVED_SUMMARY distinct. ORIGINAL_TEXT and PASTED_QUOTATION remain available. A supplied historical translation or quotation need not invent an unavailable upstream original. Its supplied provenance records what is actually known.

Each representation records id, type, positive revision, supply_status, provenance, parents, spans, verification and evidence_ids. Text representations also record content and language. Content equals the ordered span texts joined by separator, whose default is one newline; a space, no separator, or two newlines may be explicit. A supplied record has no workflow parent and retains its evidence root_id. Every derived record has direct parents, never a new independent root.

A parent link contains id, relation, revision, span_ids and snapshot. Add the supplied records first. Obtain a parent binding with `python3 scripts/source_integrity.py snapshot --state-dir "$HTI_STATE_DIR" --representation ID --spans SPAN-ID ...`; append the child with that snapshot. Each selected parent span receives a span_link with parent_id, source_span_id, target_span_id, status and an explanation for transformations or limits. PRESERVED means identical Unicode text; diplomatic transcription cannot silently alter it. CORRECTED_OCR changes require a directly inspected image/original/edition basis. Raw OCR confidence or a new label never substitutes for that review.

`python3 scripts/source_integrity.py affected --state-dir "$HTI_STATE_DIR" --representation ID --spans SPAN-ID ...` identifies descendants of a material change. Parent snapshots are span-scoped, so an unchanged unrelated span need not invalidate another branch. Changed bindings and their descendants cannot be used as current output until reviewed and rebound. This tracks representation dependencies. Source-bound ownership and body coverage use the [proposition integrity](proposition-integrity.md) extension; no historical relation follows from a representation edge.

## Page structure and reading order

Every image record retains its exact source_sha256, regions (id and class) and reading_order. Classify MAIN_BODY, RUNNING_HEAD, PAGE_NUMBER, SIGNATURE, CATCHWORD, PRINTED_MARGIN_NOTE, PRINTED_MARGIN_REFERENCE, SPEAKER_LABEL, QUOTATION_MARKER, SECTION_HEADING, FOOTNOTE_OR_NOTE, MANUSCRIPT_ANNOTATION, DECORATION_OR_ORNAMENT or UNKNOWN_REGION as applicable. An image span records region_id and the matching source_class. A derivative span retains that class. Page furniture and marginal text cannot become MAIN_BODY through a derivation.

Reading order has separate ordered sequences for meaningful blocks or columns, plus unresolved_regions and an explicit uncertainty when order cannot be resolved. Speaker apparatus, quotation markers, main body and unknown regions are accounted for. No global top-to-bottom concatenation is assumed. Preserve headings or paratext as separately identified material, not silent authorial running syntax. Signatures and catchwords retain distinct classes; a catchword repeating next-page words is sequence evidence rather than duplicated body prose.

When translating retained page furniture or marginal material, start its target span with the corresponding label from the interface, such as `Running head: `, `Margin note: ` or `Speaker label: `, and separate spans with a newline. This makes its role visible rather than joining it silently to the author's sentence. Diplomatic source forms retain their literal bytes and region classes; labels belong to the translated display layer. An excluded region keeps an explicit disposition and reason.

## Scripts and consequential reading risks

Spans record id, text, state and source_class. States are VISIBLE, UNCERTAIN, OBSCURED, LOST, RECONSTRUCTED or CONJECTURAL. Every non-visible state retains an uncertainty statement. Obscured/lost spans contain only a lacuna marker, never guessed letters. An uncertain upstream span cannot become a visible downstream reading. Witness reconstruction stays explicitly reconstructed and separate from observation.

Preserve Greek, Hebrew and other embedded forms literally in diplomatic layers. Normalization and translation are explicit transformations with reasons; a remembered biblical phrase is not a replacement. A missing span is explicit OMITTED or UNRESOLVED with a limit retained in the answer. Target spans without ancestry and unexplained duplication of one source span are rejected. A retained source-language quotation in an English translation has an explicit explanation; it must not masquerade as translated English. These checks constrain declared source transformations; they do not infer a perfect translation from fluency.

The risks list records id, representation_id, span_ids, category, status, finding and an inspected basis when reviewed. Categories include NEGATION, MODAL, ADVERSATIVE_CONCESSIVE, QUANTIFIER, SCOPE_TERM, SPEAKER_MARKER, QUOTATION_BOUNDARY, TECHNICAL_TERM, PROPER_NAME, BIBLICAL_LEMMA, ORIGINAL_LANGUAGE_FORM, CITATION_LOCATOR and PARATEXT_BODY_BOUNDARY. Status is REVIEWED, UNRESOLVED or RETAINED_UNCERTAIN. Keep uncertainty local and consequential; there are no numerical confidence scores. Unresolved high-risk material cannot license stronger original-wording or author-position claims.

## Review and permissions

Verification is attached to the record and layer actually reviewed: LAYOUT, TRANSCRIPTION, NORMALIZATION, TRANSLATION, PROPOSITION_OWNERSHIP or HISTORICAL_RELATION. A review records status, inspected basis IDs and a note. Translation review never verifies transcription; transcription never establishes edition or exemplar. Ownership and historical-relation states carry an externally performed adjudication, not an inference supplied by this substrate.

The uses list declares each representation_id, purpose and relevant span_ids. Raw OCR and unreviewed OCR descendants remain limited to discovery, search leads, source/topic nomination, possible-parallel nomination or explicitly provisional text. A corrected OCR record may pass beyond quarantine only after transcription review against its actual direct-source ancestry. Exact wording and transcribed-wording licenses require that layer's review; secure ownership requires its own review. Direct dependence, edition fact and specialization fact always require separate evidence beyond this record.

Bind checkpoint source evidence_ids to the representations actually used. For a page-anchored Scholar View, the adapter also creates `E-SUPPLIED-PAGE`; bind that ID to the supplied-image record together with any task evidence IDs for that image. Claims cannot acquire a stronger license merely by referring to an evidence ID. Output_bindings identifies the representation_id and field for each supplied-source output layer. Use field `translation` for the complete translation field, with exactly matching content and a translation representation type; use `rendered_source_layer` for another displayed source layer. Its content occurs exactly in the rendered answer. Preserve unresolved risk findings, order uncertainty and transformation limits verbatim in the appropriate uncertainty or notes field. The apparatus stays internal except where a limit changes the reading or answer.

Run `python3 scripts/source_integrity.py audit --state-dir "$HTI_STATE_DIR"` before completion when useful. Both terminal helpers enforce these checks, bind integrity bytes and task contract into the completion receipt, then preserve the existing one-response terminal operation. A helper error requires structured correction and retry. Existing task directories created with the older task contract can Continue without rewriting their completed evidence; new task creation always uses the integrity contract.

## Current accountable publication

The common `publication_contract` and response-plan digest in [output templates](output-templates.md) govern this feature's substantive output and selected-operation outcome. A retained result is not fulfillment of a new request. Publish selected current exact projections or reviewed current derivations; disclose a current PARTIAL/UNRESOLVED/BLOCKED reason when a selected operation cannot be completed. Preserve native source, ownership, uncertainty, identity and relation licenses. Unrequested operations remain optional. All research, source inspection, corrections, preparation and progress updates precede the committed response. Design R selects transport from exact UTF-8 bytes: DIRECT_STDOUT at or below 24,000 bytes emits the committed answer and stops with no later tool; READ_COMMITTED_FILE above that ceiling emits a short current-publication path/hash/byte-count stub, followed only by one exact Read with allow_large=true, exact relay and stop. No other post-stub tool, narration, editing or new publication is permitted. Later truthful recovery preserves the same commit and repeats its direct payload or bound stub, never scholarship.

The common scope selects current source bindings; it does not delete or rewrite retained output_bindings, body coverage or source representations. SOURCE_SPAN references use current parent_snapshot(representation_id, span_ids), existing purpose permissions and exact projections. An empty span list selects the complete representation; a selected span list projects those exact spans in canonical order. FULL translation requires complete selected translation binding and gap accounting. A CORRECTION selects required affected content and a governed correction account. Unknown source anchors grant only actual source-level permissions, never named-work identity.

Completed publication turnover preserves its input-bound checkpoint, plan and source-integrity bytes in the existing owned publication history. Retained source references must match historical and current span snapshots. A changed span is new/corrected material requiring review and selected correction; unchanged independent spans may remain retained. Older receipts without a saved substrate may prove retention only when their recorded source-integrity hash equals the unchanged current bytes; never manufacture a historical snapshot. These archives confer no current identity or evidence license.

## Scholar View from supplied text

Keep the scholar route for a non-image request. Register the actual primary text in source-integrity.json and set compact source_anchor to {"representation_id":"ACTUAL-ID","evidence_id":"PRIMARY-ID"}; bind that evidence ID on its representation. The adapter supplies that primary evidence item, so do not duplicate it in task.evidence. Keep locus.page_id and image_sha256 null. Set sections.supplied_text to the exact registered content; it displays in Notes, with the actual representation layer and unavailable image apparatus disclosed through current governed assertions. Do not label normalized supplied text photographed diplomatic Latin. Non-image tasks omit diplomatic_latin and rare_book_notes; normalized_latin is permitted only for an actual NORMALIZED_TRANSCRIPTION anchor. Required non-image sections are supplied_text, textual_uncertainties, theological_loci and exegetical_method, with the same witness status discipline.

The selected SCHOLARLY_TRANSLATE outcome is PARTIAL with actual current results, a visible specific reason and limitations for unavailable image-dependent apparatus. COMPLETED would falsely complete that apparatus; total BLOCKED would discard useful work. Preserve the full translation, gaps and uncertainty. ORIGINAL_TEXT retains its own permissions; RAW_OCR and derivatives remain provisional unless genuinely reviewed; historical/modern translations cannot establish underlying wording or glyphs. Primary text or its derivative is not an independent comparator. Explicitly analyzed Greek/Hebrew from supplied text uses source_layer supplied_text and its primary reading evidence, never a false image check.

For actual image tasks retain exact locus/hash and E-SUPPLIED-PAGE binding, diplomatic and normalized separation, prepare-long-s, real image attestation, high-risk gates and finite registered inspection. For non-image tasks prepare-long-s reports inapplicability without manufacturing a checklist; structured completion remains mandatory and all core source permissions still apply.
