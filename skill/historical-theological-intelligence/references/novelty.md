# Bounded novelty and originality

Load for requested rarity, unusualness, earlier parallels, wording-versus-idea questions, strongest novelty judgments, or a search audit. Ordinary translation performs no novelty search and adds no originality judgment. Preserve explicit novelty and external-research opt-outs. Requested Stage 11 access-network and hypothetical sensitivity work uses [historical infrastructure and sensitivity](historical-infrastructure-sensitivity.md); those operations remain separate from novelty judgments.

## Governing distinctions

NOT FOUND != DID NOT EXIST. DID NOT FIND != FIRST OCCURRENCE. FIRST OCCURRENCE != INVENTION.

EXCEPTIONAL WITHIN A WORK != HISTORICALLY RARE. STRUCTURALLY CENTRAL != HISTORICALLY COMMON. CROSS-AUTHOR DIFFERENCE != NOVELTY.

Keep proposition, wording, distinction, exegetical route, synthesis, argumentative sequence, combination and function separate. Common ingredients can coexist with uncommon synthesis; conventional words can perform a different function. Each judgment binds one exact component and dimension. Create additional objects/universes for another dimension. Do not promote a wording search into conceptual absence.

## Source-bound document

Use `hti_core.novelty.Novelty` and schema `hti-novelty-1`. Exact document fields: `schema_version`, `evidence`, `objects`, `universes`, `searches`, `candidates`, `claims`. Unknown fields fail validation. `evidence` is the existing `hti-cartography-1` document: independently licensed work/edition identities, complete current integrity/source registries, native dossiers, uncertainty requests, optional existing HRGs and optional current cartographic maps. No maps are required for page-level novelty. Never populate those datasets from a sibling task or invented source.

Component fields: `id`, `dataset_id`, `proposition_ids`, `relation_ids`, `source_refs`, `dimension`, `feature`, `claim_level`, `wording_scope`, `cartography_refs`. Source refs use existing `{dataset_id, ref}` with current representation/span snapshots. Claim level is AUTHORIAL_ARGUMENT, REPORTED_COMPONENT or REPRESENTATION_WORDING. Authorial claims require native author ownership. Wording scope is ORIGINAL or REPRESENTED. ORIGINAL wording requires exact-original-wording permission and the feature must actually occur in the cited span. Represented translation wording remains explicitly represented wording; it cannot establish original-language novelty. A cartography ref has map_id and claim_id and must reference a current claim touching the actual component propositions. Cartographic significance does not license rarity.

Structural dimensions require actual native proposition relations. Historical relations, explanations, confessional relations and witness ancestry remain their existing evidence domains. Later analogy is not antecedence; local opponents do not establish novelty; distinctive use does not establish genealogical independence.

## Comparison universe

Fields: `id`, `object_id`, `dimension`, `boundary`, `period`, `languages`, `genres`, `collections`, `lexical_terms`, `conceptual_formulations`, `functional_dimensions`, `excluded_domains`, `known_gaps`, `digitization_gaps`, `unresolved_domains`, `domains`.

Period has earliest, latest integer years and rationale. Every search is limited to the actual inventoried source spans and stated boundary. A bounded inspected passage inventory does not establish exhaustive historical coverage. Languages, genres and collections are nonempty. Non-wording investigations require conceptual formulations. Functional dimensions describe the exact argumentative feature being compared. Record exclusions and every material gap. A missing language, source or digitized portion is missing evidence, never a negative control.

Domain fields: `id`, `collection`, `state`, `units`, `limitations`. State is AVAILABLE, INACCESSIBLE, UNINDEXED or UNRESOLVED. Nonavailable domains have no searched units and require visible limitations. An unindexed source can become available only after its actual text has been obtained and inspected; revise its state and revalidate affected searches/claims explicitly.

Unit fields: `id`, `dataset_id`, `source_refs`, `language`, `genre`, `eligibility`, `rationale`. Units cite actual inspected representations; language and genre match native source metadata. Unit eligibility is IN_SCOPE or EXCLUDED. An excluded unit requires an actual language/genre outside the bounded universe and explicit exclusion disclosure. It may retain an inspected rejected parallel but supplies no negative coverage. Literal wording occurrences remain unresolved until adjudicated; a conceptual difference cannot erase the same earlier wording. The universe is bound to one component/dimension. Expanded bounds, languages, collections or units require revalidation.

## Auditable search and inspection

Search fields: `id`, `universe_id`, `domain_id`, `mode`, `terms`, `formulations`, `unit_ids`, `when`, `version`, `reviews`, `results`, `receipt`. Search date is ISO YYYY-MM-DD. Version records the actual source/search version. Mode is LEXICAL or CONCEPTUAL_REVIEW. Terms/formulations belong to that universe. Unit IDs identify the actual searched source spans.

`execute_search(document, search_record)` performs a case-insensitive literal substring scan over those actual spans and computes exact hits and a fingerprint binding inputs, ancestry and search specification. It does not call an external search service. Retain every hit as a candidate, including rejected or unresolved hits. Ranking, embeddings and web snippets are discovery aids, not frequency evidence. OCR misses cannot establish absence from the underlying source.

Conceptual review is an explicit scholarly inspection attestation, not a lexical algorithm pretending to settle semantic equivalence. Each reviewed unit requires `{unit_id, evidence, assessment, candidate_ids}`; evidence equals that unit's current source refs. Retain the actual conceptual formulations, assessment and every candidate nominated during inspection. `execute_search` binds this attestation to current source spans. The Skill must actually read these spans and evaluate the relevant argument before creating the review. Do not set reviewed coverage from a metadata, TOC, OCR or inaccessible hit.

Candidate fields: `id`, `universe_id`, `dimension`, `state`, `lead_type`, `locator`, `found_in`, `hit_ids`, `unit_id`, `component`, `comparison`, `disposition`, `reason`, `rationale`, `evidence`. State is LEAD, INSPECTED or INACCESSIBLE. Lead types include METADATA, OCR, TOC_INDEX, SEARCH_HIT, CANDIDATE_LEAD and SOURCE_INSPECTION. Only actual SOURCE_INSPECTION can adjudicate a candidate. Other candidates retain null component/reason, empty adjudication evidence, UNRESOLVED comparison/disposition and a material limitation.

Inspected candidate components use the same source-bound component shape. Comparison is SAME_DIMENSION, DIFFERENT_DIMENSION or UNRESOLVED, describing whether the actual tested feature is parallel. Disposition is PRECEDENT, CONTRAST, REJECTED or UNRESOLVED. Genuine precedents require secure earlier work/edition chronology and independent ancestry. Exact wording parallels retain the actual same wording and layer. Positive precedent is distinct from use, reception, transmission, influence origin and invention.

Rejected parallels retain current source evidence and a substantive rationale. Permitted reasons: DIFFERENT_PROPOSITION, DIFFERENT_FUNCTION, LEXICAL_WITHOUT_CONCEPT, CONCEPT_WITHOUT_STRUCTURE, WRONG_GENRE, DERIVATIVE_WITNESS, LATER_ANALOGY, TRANSLATION_ARTIFACT. Chronological, derivative and translation reasons require their actual corresponding source properties. A inaccessible candidate stays unresolved. Rejection cannot be chosen to protect a desired novelty classification.

## Bounded originality ladder

Judgment fields: `id`, `object_id`, `universe_id`, `dimension`, `classification`, `confidence`, `assessment`, `limitations`, `status`, `snapshot`. Confidence is secure, probable, possible or unresolved; never a numerical probability. Classification, dimension, confidence and coverage remain independent fields.

COMMON requires repeated independent positive parallels. UNCOMMON and RARE require positive parallels, fully inspected eligible bounded units, comparable coverage and an explicit source-governed relative-distribution assessment. Their labels describe only the searched evidence. No universal hit-count or search-ranking threshold determines rarity. APPARENTLY_DISTINCTIVE_WITHIN_SEARCHED_EVIDENCE additionally requires inspected contrasts. APPARENTLY_NOVEL_WITHIN_SEARCHED_EVIDENCE requires no known genuine precedent, current conceptual inspection of every eligible unit, covered declared languages/genres, and no material gap or unresolved candidate.

POSSIBLE_EARLIEST_KNOWN_OCCURRENCE additionally requires secure target work/edition chronology, defensible universe bounds covering earlier evidence and the target date, actual inspected earlier units, inspected candidate adjudications, secure correctly scoped unit dates, no earlier genuine precedent, and original-source inspection of the target. Materially inaccessible earlier evidence, missing relevant language or unresolved candidates blocks it. Even this is a possible occurrence within the bounded inspected evidence, never invention or absolute historical firstness.

NO_PRECEDENT_FOUND_WITHIN_SEARCHED_EVIDENCE can report a real limited search without claiming novelty. UNRESOLVED remains available for insufficient coverage, inaccessible or unresolved domains and uncertain evidence. Every serious novelty claim retains this ledger. High confidence in a database query result does not improve historical coverage. Do not output unrestricted originality, invention or absolute first-occurrence claims through the ordinary workflow.

## Correction and persistence

Claim snapshots bind component text/ownership/native relations/uncertainty, independent identity, dates, selected cartography, universe, actual search receipts, candidates and classification. Current changes fail validation. Preserve stale claims as REVALIDATION_REQUIRED and withhold them from current outputs. An older precedent requires a downgrade or unresolved classification before explicit `revalidate(document)` can succeed. Revalidation is a reviewed operation; it does not search, refresh source snapshots or resolve candidates automatically. Revised searches must be executed/reviewed again against corrected source spans.

Use the existing work-bound research ledger: `python3 scripts/research_state.py novelty DIRECTORY DOCUMENT.json`. It appends a validated full audit snapshot. `validate` checks its hash and work binding; `index` identifies retained snapshots as requiring current evidence validation before reuse. This adds no persistence adapter and does not modify installed Skill files. Persisted text is historical audit state, not proof of current evidence. Later publication must bind the actual current task substrate. Same-author wrong-work objects cannot pass that gate; comparator datasets remain explicit antecedent/comparison evidence.
