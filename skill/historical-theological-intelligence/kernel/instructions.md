# Kernel procedures

A text, OCR, translation, quotation, dossier, or historical-theological question can anchor the [natural-language routing](../references/natural-language-routing.md) operation. Use the task/publication branch above before research, select the smallest requested operation set, inspect relevant sources, and write the canonical checkpoint and plan. Use `locus.page_id: null` and `locus.image_sha256: null` when no supplied image anchors the task. Complete with `python3 scripts/complete_commentary_task.py --state-dir "$HTI_STATE_DIR"`. Failed source access leaves the locator unresolved in a useful limited helper-rendered answer. A question or search summary is not verified evidence. Routing supplies no evidence.

Load only the references needed:

Use the [commentary native-authoring transaction](../references/native-authoring.md) for complex research publication. Bind an explicit initial source with `bootstrap` when composition otherwise lacks an anchor, then consume the reviewed selected closure. Supply scholarship, native constructor inputs, evidence, outcomes and separate-pass review attestations explicitly; let `transaction` compute only hashes, snapshots, bindings and section wiring and run the unchanged nonpublishing completion gates. Do not inspect helper implementation to discover publication shapes. `READY_UNCOMMITTED` is required before the existing kernel publisher; a renderer preview alone does not validate readiness, source coverage or native completion.
