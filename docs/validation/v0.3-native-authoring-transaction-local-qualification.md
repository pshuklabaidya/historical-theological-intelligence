- constructor invocation for existing native HTI objects;

- source, proposition, relation, and parent snapshots;
- current-publication binding;

- source and domain-output bindings;

The transaction does not accept prebuilt `hti-*.json` native files as its scholarly interface. It accepts the existing constructors' scholarly inputs and produces the native files through those constructors.
