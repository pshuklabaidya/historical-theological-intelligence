# Historical-Theological Intelligence

**Historical-Theological Intelligence (HTI)** is an evidence-governed research system for reconstructing how historically located exegetical and theological arguments are constituted, situated, transmitted, transformed, received, and related to historic doctrinal formulations across periods, languages, and source forms.

HTI targets **Claude's Skill System**.

## Core object

HTI treats the **historically located argument or argument-component** as its primary object of analysis.

A single argument may combine components with different histories - textual observations, grammatical or philological inferences, patristic propositions, medieval distinctions, scholastic forms, inherited exegetical commonplaces, Reformation syntheses, and later receptions. HTI keeps those components separable before proposing larger historical relations.

## Core capabilities

The current v0.3 development line extends a rigorously evidence-governed translation and textual-analysis foundation into:

- argument architecture reconstruction
- proposition-relation analysis
- dependency-sensitive uncertainty
- bidirectional intellectual lineage tracing
- source-transmission forensics
- immediate-source adjudication
- reception and mutation analysis
- conceptual-history tracking
- evidence-ancestry tracking
- confessional and creedal locus tracing
- confessional formulation comparison
- work-specific historical-theological specialization

## Evidence discipline

HTI is built around several non-negotiable distinctions:

- supplied-source observation is not reconstruction
- reconstruction is not conjecture
- similarity is not genealogy
- chronology is not influence
- citation is not proof of immediate source
- historical translation is both a mediated representation and, where appropriate, a reception event
- textual-witness relations remain distinct from intellectual-historical relations
- doctrinal correspondence remains distinct from historical dependence
- relation type remains distinct from confidence
- uncertainty propagates through actual dependencies
- repeated inspection of the same evidence does not create independent evidence

## Natural-language use

HTI is designed for ordinary scholarly requests rather than mandatory mode syntax.

Representative requests include:

```text
Using HTI, translate these pages.
Using HTI, what is this argument made of?
Using HTI, trace this argument backward and forward.
Using HTI, where did this distinction come from?
Using HTI, how did this source reach the author?
Using HTI, trace this locus through the Reformed confessions.
```

## Project lineage

HTI grew from a deeply validated workflow for printed early-modern Latin biblical commentaries and related exegetical-theological works. Its later architecture generalizes the underlying evidence discipline without making any one author, work, period, language, or witness hierarchy normative.

The frozen `Vermigli-Judges-Translator` v1.3 implementation remains a separate reference implementation and is not part of the general HTI production package.
